# Changelog

All notable changes to SC-EVM will be documented in this file.

## [v0.1.0-developer-preview] - 2026-07-13
- First developer preview release of SC-EVM middleware.
- Session isolation via local volatile registry and ChromaDB collections.
- Staged response delivery via Server-Sent Events (SSE).
- Dynamic outlier distance gating.
- Live security validation suite and offline evaluation runner.
