# Benchmark Limitations

SC-EVM evaluations are subject to the following limitations:

## Limitations
- **No Comparative Marketing Claims:** All comparative benchmarks generated on development splits are invalid for general marketing claims.
- **NVIDIA Transport Specificity:** The LLM transport layer is currently implemented exclusively for the NVIDIA NIM API. It is provider-adaptable but not provider-independent.
- **Graphify Experimental Status:** Graphify remains an experimental capability. Ablation campaigns indicate it results in a null quality effect.
- **Staged Response Delivery:** Response stream telemetry is not optimized for production latency profiles.
