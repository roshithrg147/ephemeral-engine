# Project Roadmap & Current Status

SC-EVM is currently in **Developer Preview (v0.1.0-developer-preview)** status.

## Future Milestones
- **Authentication Hardening:** OIDC validation and session ownership are implemented; remaining gates are deployed CORS evidence, rate limits, external threat review, and operational readiness.
- **Multi-Provider Clients:** Extend model connectors to support HuggingFace, Anthropic, and VertexAI.
- **Physical Memory Sanitization:** Research techniques for hardware-level RAM erasure on session burn.
