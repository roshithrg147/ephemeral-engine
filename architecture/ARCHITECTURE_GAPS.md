# SC-EVM Architecture Gap and Liability Register

This register records unresolved architecture liabilities discovered during Day 2 canonicalization. It does not authorize implementation. Significant remedies begin through the [RFC process](../rfcs/README.md).

| ID | Description | Evidence | Impact | Severity | Pillar | Recommended action | RFC? | Blocks benchmark? | Blocks public pilot? | Blocks production? |
|---|---|---|---|---|---|---|:---:|:---:|:---:|:---:|
| AG-001 | No application-user authentication or authorization | API accepts client-supplied session IDs and exposes session list; no auth middleware in `src/main.py` | Any network client can enumerate and access sessions | Critical | Isolation, Control | Define authenticated principal, authorization rules, and session ownership before public exposure | Yes | No | Yes | Yes |
| AG-002 | Provider boundary is incomplete | One `ModelConnector` delegates to NVIDIA-only transport; no normalized errors/usage/capabilities | Provider changes require strategy and transport assumptions to be reconciled | High | Control | Resolve reserved RFC-0004 with a minimal capability and error contract | Yes | No | No | No |
| AG-003 | Durable JSON memory has limited concurrency semantics | `MemoryManager` uses file locking but rewrites one local JSON document | Cooperating writers are serialized, but distributed writers, recovery, and transaction history are absent | Medium | Isolation | Keep local-only scope explicit; require persistence RFC before shared deployment | Yes | No | No | Yes |
| AG-004 | API response streaming is simulated | `src/main.py` waits for complete synthesis then emits word chunks | Poor time-to-first-token and misleading streaming claims | Medium | Evidence | Measure need, then wire transport streaming only through a reviewed strategy contract | Yes | No | No | No |

## Priority interpretation

- **Public pilot blockers:** AG-001, AG-007, AG-009, AG-013, AG-014, and AG-015.
- **Production blockers:** all public-pilot blockers plus AG-003 and AG-008.
- **Benchmark-methodology blocker:** AG-005 and AG-010 must be resolved before evidence can support quality claims.

The image and clipboard scaffolds do not block the core product when kept optional and accurately classified.
